Ping One Clicker Chrome Extension

Automatically clicks "Sign On" for PingOne after a configurable delay. No more staring at that button.

Features

  • Auto-clicks the PingOne "Sign On" button on authenticator.pingone.com
  • Configurable delay — choose 1, 3, or 5 seconds via the extension popup
  • Zero setup — install and it just works
  • Lightweight manifest v3 extension

Installation

  1. Open Chrome and go to chrome://extensions
  2. Enable "Developer mode" (top right)
  3. Click "Load unpacked" and select the extension folder
  4. Done!

Or install from the Chrome Web Store.

Usage

By default, the extension clicks "Sign On" after 5 seconds when you land on the PingOne authenticator page.

Click the extension icon in your toolbar to change the delay to 1, 3, or 5 seconds.
